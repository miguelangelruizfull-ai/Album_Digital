# Album_Digital

## Cápsula digital de recuerdos

Album_Digital es una plantilla para crear un álbum personal de fotografías y videos.

El proyecto nace con la idea de que cada persona pueda conservar sus recuerdos digitales organizados por fecha y categorías, sin depender únicamente de un teléfono celular.

## Características iniciales

- Galería digital.
- Organización cronológica.
- Categorías personalizables.
- Diseño adaptable.
- Sin fotografías ni información personal incluida.

## Personalización

Editar:

`config/album.json`

para cambiar:
- Nombre del álbum.
- Autor.
- Descripción.
- Categorías.
